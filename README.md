# Deploying a Scalable ML Pipeline with FastAPI

This project builds and deploys a machine learning pipeline using FastAPI.  
The application predicts whether an individual's income is greater than 50K based on census data.

## Link to my Github Repo: 

https://github.com/KAIREED99/Deploying-a-Scalable-ML-Pipeline-with-FastAPI

## Features

- Data preprocessing and model training
- Model evaluation using precision, recall, and F1 score
- FastAPI deployment for inference
- Unit testing with pytest
- Continuous Integration using GitHub Actions
- Model serialization using pickle

## Technologies Used

- Python
- FastAPI
- Scikit-learn
- Pandas
- Pytest
- GitHub Actions
- Uvicorn
